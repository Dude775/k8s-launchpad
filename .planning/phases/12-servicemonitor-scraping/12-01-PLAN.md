<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator shell → Prometheus HTTP API | Install script queries /api/v1/query over a local port-forward (already-trusted localhost, same pattern as make smoke) |
| ServiceMonitor namespaceSelector → cluster namespaces | Declares which namespaces Prometheus searches for scrape targets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Information Disclosure | ServiceMonitor.spec.namespaceSelector | mitigate | Pin `matchNames: ["default"]` (D-06) — narrow, explicit; never `{}`/wildcard, so future namespaces are not accidentally scraped |
| T-12-02 | Tampering | curl PromQL query string under Git Bash | mitigate | All queries are fixed code constants (`up{job="field-guide-api"}`); use `curl -G --data-urlencode` so the matcher is percent-encoded, no shell/PromQL injection surface (V5) |
| T-12-03 | Denial of Service | up==1 poll loop | accept | Bounded 150s deadline with sleep 5; no unbounded/watch wait (kubectl wait forbidden — hangs on this host). Local single-tenant kind cluster |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | No package installs, no new container images this plan — only two static YAML manifests and a bash diff; Package Legitimacy Gate not applicable |
</threat_model>
