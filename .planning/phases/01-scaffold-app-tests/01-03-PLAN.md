<objective>
Prove the field-guide API works without a cluster or real database. This plan delivers a pytest suite that covers every endpoint with MongoDB mocked in-memory, plus a minimal Makefile whose `test` target runs the suite with coverage. The green suite is the phase's correctness gate — it must pass on a laptop with no Docker, no kind, and no MongoDB running.

Purpose: The whole point of an app factory + env config (Plan 02) is testability. This plan exercises that seam so regressions are caught before anything is containerized. It also seeds the Makefile that Phase 4 will extend with the cluster targets.
Output: `tests/` package with conftest fixtures and endpoint tests, `requirements-dev.txt`, `pytest.ini`, and a root `Makefile` with a `test` target.
</objective>
