<objective>
Establish the monorepo skeleton and git hygiene BEFORE any application code exists. This plan produces the first meaningful commit: `.gitignore` + `.gitattributes` guarantee that no secret, virtualenv, python cache, or kubeconfig can ever enter history, and that no shell script inherits CRLF endings that would break inside containers or WSL2/Git Bash.

Purpose: Git hygiene is a one-way door — a secret committed once lives in history forever. Establishing ignore rules and LF enforcement as the first commit is the single most important safety step of the milestone.
Output: `.gitignore`, `.gitattributes`, a stub `README.md`, and the full target directory layout with placeholder seams for PRD-2 (`infra/argocd/`) and PRD-4 (`infra/observability/`).
</objective>
