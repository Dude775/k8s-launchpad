<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → Flask route/form | Untrusted POST body (name, repo_url, owner, description, environment) crosses into ServiceForm validation |
| app → MongoDB | Service name flows into a MongoDB equality query and insert |
| pip → build | Flask-WTF/WTForms wheels enter the supply chain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | ServiceForm repo_url validator | mitigate | URL(require_tld=True) + explicit http(s) scheme restriction (Pitfall 5) rejects javascript:/ftp: schemes before persistence |
| T-09-02 | Tampering | services.name used as a Mongo query key | mitigate | Regexp(^[a-z0-9-]{2,40}$) validates name before any Mongo equality match; PyMongo dict-encoded query (never string-interpolated, never $where) is injection-resistant |
| T-09-03 | Information Disclosure | register_service error path | mitigate | never-raise helper returns fixed generic strings (locked UI-SPEC copy); never str(exception) in any return value (T-08-06 discipline) |
| T-09-04 | Elevation of Privilege | CSRF token signing key | mitigate | SECRET_KEY sourced from env with a clearly-labeled non-production dev default; real value delivered in-cluster via chart Secret (Plan 09-03, D-05) |
| T-09-05 | Denial of Service | events collection unbounded growth | mitigate | TTL index on events.ts with expireAfterSeconds default 604800 created idempotently at startup (FEED-03, D-10) |
| T-09-SC | Tampering | pip install Flask-WTF/WTForms | mitigate | blocking human-verify checkpoint (Task 1) confirms pallets-eco provenance before pinning; [ASSUMED] per graceful-degradation (slopcheck unavailable) |
</threat_model>
