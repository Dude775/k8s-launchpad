## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /catalog/new, POST /catalog/<name>/delete | State-changing requests crossing into the app |
| service.name / service.description → rendered HTML | User-supplied strings echoed into templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Spoofing / Tampering | POST /catalog/new and POST /catalog/<name>/delete | mitigate | CSRFProtect app-wide (09-01); both POST forms carry a token (form.hidden_tag()/csrf_token()); one CSRF-enabled test proves missing-token → 400 (CAT-03, D-04) |
| T-09-07 | Tampering / Information Disclosure | detail.html / catalog.html rendering description + free-text fields | mitigate | Jinja2 auto-escape on every `{{ }}`; no `| safe` on any user-supplied field |
| T-09-08 | Information Disclosure | form/route error paths | mitigate | fixed locked UI-SPEC error copy only; never str(exception) in any response (T-08-06) |
| T-09-09 | Tampering | /catalog/<name> path segment used to look up a document | mitigate | get_service uses a plain equality match on a name already constrained by the 09-01 Regexp at write time; PyMongo dict-encoded query, no $where, no string interpolation |
</threat_model>
