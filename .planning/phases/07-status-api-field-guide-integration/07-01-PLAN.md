<objective>
Wire launchpad's own MongoDB (Flask-PyMongo) and evolve the Phase 5 `/health` stub into a real
Kubernetes-readinessProbe-safe readiness check that pings ONLY launchpad's own MongoDB and never
touches field-guide-api. This plan establishes the `mongo` singleton, the config keys, and the
mongomock-backed test harness that Plan 02's status-aggregation work depends on.

Purpose: STAT-03 requires `/health` to return 503 when launchpad's own DB is unreachable and 200 when
reachable, never reaching downstream services. This is the Kubernetes readinessProbe contract Phase 8
will wire unchanged — it must be correct now. This plan also creates the interface (the bound `mongo`
extension + config keys + test fixtures) consumed by Plan 02.

Output: `mongo` PyMongo singleton bound in the app factory (2000ms serverSelectionTimeoutMS), three new
config keys, three new direct dependency pins, a mongomock base test fixture + `mongo_down` fixture, an
updated `test_factory.py` (stale MONGO assertion removed), and `/health` returning 200/503.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| kubelet → /health | Kubernetes readinessProbe polls /health; a 503 removes the pod from Service Endpoints |
| Flask route → launchpad MongoDB | Own-DB wire-protocol call (`admin.command("ping")`); MONGO_URI is env/Secret-injected, never client-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | /health Mongo ping blocking the sole gunicorn worker | mitigate | serverSelectionTimeoutMS=2000 bounds worst-case /health latency to ~2s instead of PyMongo's 30s default (RESEARCH Pitfall 3) |
| T-07-02 | Information Disclosure | /health error path | mitigate | bare `except Exception` returns a fixed-shape 503 body ({"status":"unavailable","mongo":"down"}) — never str(exception), no hostname/stack trace/connection-string leak |
| T-07-03 | Elevation of scope / coupling | /health accidentally reaching field-guide-api | mitigate | health.py imports ONLY app.extensions.mongo; grep gate asserts no `requests`/`FIELD_GUIDE` substring (Pitfall 1); readinessProbe must reflect only this pod's own readiness |
| T-07-04 | Information Disclosure | MONGO_URI credential handling | accept | MONGO_URI is env/Secret-sourced with a credential-free local default; .env is gitignored; mirrors field-guide-api's existing secret.yaml discipline — no new secret surface introduced here |
| T-07-SC | Tampering | pip installs of Flask-PyMongo / pymongo / requests / mongomock | mitigate | Task 1 blocking-human legitimacy gate for the three [ASSUMED] packages before install; post-install pip show version verification |
</threat_model>
