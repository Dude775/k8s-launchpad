<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Flask page/partial routes | Inbound HTTP; all routes GET-only, no query params consumed, no user input accepted this phase |
| Flask template render → browser HTML | Status/text values rendered into HTML; Jinja2 autoescaping is the XSS control |
| Flask /static → browser | Vendored assets served; no dynamic content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Tampering / Elevation of Privilege | Reflected/stored XSS via unescaped template output | mitigate | Rely on Jinja2 default autoescaping (Flask enables it for .html); `| safe` is FORBIDDEN on every value in all six templates; Phase 6 has no user-controlled text source, but the rule holds as Phase 7/9 add dynamic fields |
| T-06-04 | Tampering | CDN reference shipped in a rendered template | mitigate | UI-05 no-CDN rule; all asset refs via url_for('static', ...); test_no_cdn_references enforces absence of unpkg/cdn/http(s) external src/href across all four routes |
| T-06-05 | Information Disclosure | Secrets/config leaking into client-rendered HTML | mitigate | Templates render only static copy + the degraded-status stub (no config, no env vars, no secrets passed to render_template); status_cards stub passes only status="unknown"/cards=[] |
| T-06-06 | Denial of Service | Fragment route mutated into a full page, breaking the Phase 7 contract | accept | Documented fragment-only docstring (RESEARCH Pitfall 3); test asserts `<html` absent; low risk, single-user local platform |
| T-06-SC | Tampering | Vendored asset supply-chain | mitigate | Handled by Plan 06-01 blocking-human checkpoint; carried here for register completeness |
</threat_model>
